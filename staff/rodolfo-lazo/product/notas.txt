Node
===================

- Inicializar package.json
npm init -y

- El package.json debe de tener incluido módulos para usar import / export
type : module

- Cargar dependencias de desarrollo. (mira el package.json e instala todo lo del package.json)
npm install

- Instalar vite como dependencia de desarrollo
npm i -D vite @vitejs/plugin-react
npm install vite --save-dev

Forma antigua de instalar vite
npm init -y
npm install vite
npx vite

Forma nueva de instalar vite
npm create vite@latest mi-proyecto
cd mi-proyecto
npm install
npm run dev

- Ejecutar vite
npm vite
npx vite

- Ver árbol de dependencias nivel de profundidad 10
npm list --depth:10

- Agregamos : vite.config.js a la raiz del proyecto

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
    plugins: [react()]
})

- Instalamos react
npm i react react-dom


- Tunel con cloudflared
cloudflared tunnel --url http://localhost:8080

Debug en Node
node --inspect-brk index.js
