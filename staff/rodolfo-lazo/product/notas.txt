VITE
========================================================================================

- Inicializar package.json
npm init -y

- El package.json debe de tener incluido módulos para usar import / export
type : module

- Cargar dependencias de desarrollo. (mira el package.json e instala todo lo del package.json de un proyecto existente)
npm install

- Instalamos react
npm install react react-dom

- Instalar vite y plugin-react como dependencia de desarrollo
npm install vite --save-dev
npm i -D vite @vitejs/plugin-react

- Agregamos : vite.config.js a la raiz del proyecto

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
    plugins: [react()]
})

- Ejecutar vite
npm vite
npx vite

========================================================================================
Forma antigua de instalar vite
npm init -y
npm install vite
npx vite

Forma nueva de instalar vite
npm create vite@latest mi-proyecto
cd mi-proyecto
npm install
npm run dev

- Ver árbol de dependencias nivel de profundidad 10
npm list --depth:10
